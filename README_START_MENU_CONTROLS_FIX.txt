FIX FOR CONTROLS + START MENU
Unity project: C:\Users\prani\jungle

1. Stop Play mode.
2. Extract this ZIP.
3. Copy Assets\JungleRush3D into C:\Users\prani\jungle\Assets and choose Replace.
   Do not copy the Editor folder again; your existing scene builder is unchanged.
4. Return to Unity and wait for compile.
5. Press Play. START RUN menu appears.
6. Click inside Game view once if keyboard input does not respond, then use:
   Left/Right or A/D = lanes; Space/W/Up = jump; S/Down = slide.
7. After Game Over click MAIN MENU / RESTART to reload the scene and start again.

This version reads Unity's new Input System when ENABLE_INPUT_SYSTEM is active,
or the legacy Input Manager otherwise. It still uses procedural Unity primitives
for the environment; realistic imported models are a separate art upgrade.
