JUNGLE RUSH 3D — Fresh 3D runner prototype

Target project: C:\Users\prani\endless runner

1. Stop Play mode in Unity.
2. Extract this ZIP.
3. Copy the folder `Assets\JungleRush3D` and the file `Assets\Editor\JungleRush3DSetup.cs` into your Unity project's `Assets` folder.
4. Wait for Unity to compile.
5. Choose `Jungle Rush 3D > Create Playable 3D Scene`.
6. Press Play.

Controls:
A/D or Left/Right: switch lanes
Space/W/Up: jump
S/Down: slide
On-screen buttons or 1/2/3: change runner appearance
Collect coins, jump over logs, slide under low barriers, avoid collisions.

The environment is procedurally built with Unity primitives, so it runs without external asset downloads. It is a playable 3D prototype; high-end Temple Run art/animations would require imported 3D assets.
